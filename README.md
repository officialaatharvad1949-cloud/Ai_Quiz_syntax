What I built:
An AI-powered Quiz Bot that integrates the Gemini API to generate custom quizzes based on user-selected topics. It features a robust UserProfile system for tracking game statistics and a QuizManager class to orchestrate the quiz flow.

How I built it:
I architected the application using a modular class-based approach in JavaScript. I focused heavily on the data pipeline, ensuring the raw JSON array generated by the Gemini API was properly parsed and fed into the QuizManager to drive the UI, timer logic, and score tracking.

What I would change if I built it today:
I would aggressively refactor the codebase to reduce the number of single-use functions. During development, I tended to define almost every minor operation as its own function, which led to a bloated codebase that became difficult to navigate. Today, I would use more functional composition and move shared logic into reusable utility modules to keep the QuizManager cleaner and more maintainable.

AI vs. My Contribution:

AI Helped With: Generating boilerplate code for the Gemini API integration and suggesting JSON structures for the quiz data.

What I Figured Out: The entire architecture and data flow. The hardest part was synchronizing the asynchronous API response with the front-end rendering logic—this took 80% of my development time.

Where AI Failed: The AI struggled with context-aware code refactoring. It often provided "localized" fixes that renamed vital variables according to generic conventions, which consistently broke the integration with my existing code base. I had to manually audit every AI suggestion to ensure variable naming consistency and architectural integrity.
